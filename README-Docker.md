# Запуск генератора дорожной карты через Docker

## Что нужно

Установленный Docker Desktop (Windows/macOS) или Docker Engine + Compose plugin (Linux). Go устанавливать не нужно.

## Первый запуск

1. Скачайте и распакуйте репозиторий целиком. В корне должны лежать `Dockerfile`, `compose.yaml`, `template.xlsx`, `repos.yaml` и `go.mod`.
2. (Рекомендуется) Скопируйте `.env.example` в `.env` и укажите `GITHUB_TOKEN`. Без токена публичные задачи могут быть доступны, но приватные репозитории и поля GitHub Projects могут не загрузиться.

Можно без .env, просто сделать `export GITHUB_TOKEN="<token>"`

3. Запустите генератор:
   - **Windows:** двойной щелчок по `run.bat`.
   - **macOS/Linux:** выполните `./run.sh` в терминале.
   - Либо из корня проекта: `docker compose run --build --rm roadmap-generator`.

При первом запуске Docker соберёт образ и загрузит необходимые зависимости; это требует интернет-соединения. При следующих запусках образ будет использоваться повторно, если исходники не менялись.

## Результат

Новый Excel-файл будет сохранён в локальную папку `res/` рядом с проектом. Папка создаётся автоматически. Шаблон `template.xlsx` не изменяется.

Чтобы изменить список репозиториев и фильтры, отредактируйте `repos.yaml`. После изменения Go-кода или Dockerfile образ пересоберётся при следующем запуске.

`GITHUB_TOKEN` нужен для доступа к приватным репозиториям и чтения полей GitHub Projects. Создавайте токен с минимально необходимыми правами; не публикуйте файл `.env` и не добавляйте токен в репозиторий.
